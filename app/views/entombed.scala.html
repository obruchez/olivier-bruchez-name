A platform game written for the Atari ST by Nick Concannon in 1991, which I ported to Scala 3. It runs right here, in your browser. You need a keyboard or a gamepad.

Keys

Arrows
Walk, jump (up), climb ladders
Space or Ctrl
Fire: start, select a tomb, shoot arrows
P
Pause, any key to resume
1 to 9, 0
Use 1 to 10 seconds of hourglass time
S, L
The save game added in 1995 for the Smaky (during play only)
F6, F7
Save and load at any moment
F8
God mode: the man cannot die

The sound starts after the first key press.

The game

Four Egyptian tombs, in any order, then a fifth one. The tombs change while you play (they flicker before they do), and hourglasses let you delay those changes. Seven lives for the whole game and no saving: it was very hard. This port adds saving at any moment and a god mode.

History

1991
Nick Concannon releases Entombed as freeware.
1995
My brother Erik and I disassemble and comment it, then port it to the Smaky, a Swiss computer also based on the 68000.
1996
An attempt at a PC port through a 68000-to-C translator, never finished.
2026
This port, which can also run the original 68000 code through an interpreter: the button above switches between the two.

Entombed © 1991 Nick Concannon (freeware). The source code of the port is on GitHub.
